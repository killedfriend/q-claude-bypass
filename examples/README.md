# Examples

These files are templates, not drop-in replacements.

- `claude-settings/*.json` — direct-mode `~/.claude/settings.json` snippets.
  Replace the `REPLACE_WITH_YOUR_...` placeholder and **merge** the `env` block
  into your existing settings. Do not overwrite unrelated keys.
- Gateway provider presets live in `../gateway/providers/`. Those are complete
  and are the recommended way to switch providers.

Educational, non-commercial project. Use at your own risk.
